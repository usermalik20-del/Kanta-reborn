KANTA Reborn OpenStage Candidate Pack

Contents
- kanta_reborn_karaokelive_gm_v3.sf2: working karaoke-ready KANTA bank using original procedural samples.
- open_source_candidates.lock.json: pinned candidate repositories and commits.
- OPEN_SOURCE_LICENSE_AUDIT_REQUIRED.md: mandatory repository audit requirements.
- manifest.json: package hashes and status.

Important
The open-source candidates are not embedded in this SF2 yet. This execution environment could verify repository structure, pinned commits, and license-file presence, but it could not retrieve the large binary sample trees. The package therefore does not misrepresent third-party audio as integrated.

Integration target
Replace selected procedural families with audited real samples while preserving KANTA GM mapping, bank-128 drum programs, velocity layers, headroom, and TinySoundFont compatibility.
