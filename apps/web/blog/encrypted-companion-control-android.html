Encrypted Companion Control: Remote Karaoke from a Second Android

2026-09-16By KANTA Team14 min read

What Companion Control Is

KANTA's companion feature lets you control one Android device running KANTA from a second Android device. Think of it as a remote control for karaoke — your phone (or tablet) becomes the wireless controller while the host device connects to the TV and speakers.

This is ideal for karaoke hosts who want to walk around the room, queue songs, and manage the show without touching the device connected to the display.

Two Paths: Legacy and Encrypted

The legacy path works but sends data in plaintext over your local network. The encrypted KCP1 path is the modern, secure option.

How KCP1 Encryption Works

KCP1 (KANTA Companion Protocol 1) uses:

  • Device-to-device key exchange — Pairing establishes a shared secret without transmitting it over the network
  • AES-256 session encryption — All commands (song selection, queue, transport) are encrypted for the session
  • Per-session keys — A new key is generated for each connection; compromising one session doesn't expose others
  • No cloud involvement — Everything happens on your local network. No data leaves your devices.

Even if someone on your Wi-Fi is sniffing packets, they see only encrypted noise.

Pairing Process

  1. On the host device: More → Companion → Enable Companion Mode
  2. On the client device: More → Companion → Control an Android Host
  3. The client scans the local network and discovers the host
  4. Tap to pair — an encrypted key exchange happens automatically
  5. Once paired, the client shows a remote control interface: song list, queue, play/pause, next, previous, volume

Pairing is remembered. Future connections are automatic when both devices are on the same network.

Session Management

  • One host, multiple clients — Several controllers can connect to one host (useful for a karaoke host with an assistant)
  • Session timeout — Idle connections disconnect after 10 minutes
  • Reconnect — If the client loses Wi-Fi momentarily, it auto-reconnects and resumes
  • Disconnect — Either side can end the session; the host continues playing uninterrupted

Security Considerations

  • Local network only — Companion control never uses the internet. It works on airplane mode if both devices are on the same Wi-Fi.
  • Trust your network — Don't use companion control on public Wi-Fi (airports, cafes). Use it on your home or venue network.
  • Physical access matters — Anyone on your network can attempt to pair. Keep your venue Wi-Fi secured with WPA2/WPA3.
  • No data is stored — Session keys are ephemeral. No pairing data is saved to the cloud.

Use Cases

  • Karaoke host: Phone connected to TV, tablet in hand controlling the queue from across the room
  • Duet partners: One person manages songs while the other warms up
  • Venue setup: Host device locked in a equipment rack, controlled from a phone
  • Accessibility: Controller device placed where it's easier to reach than the host
