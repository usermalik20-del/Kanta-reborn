Private Songbook Export: Sharing Your Catalog Without Sharing Your Music

2026-10-07By KANTA Team3 min read

What .kanta-book Is

A .kanta-book file is KANTA's encrypted container for your song catalog. It doesn't contain audio — it contains metadata: your song list, artists, and your custom song codes.

Think of it as your library's card catalog, not its shelves. You can export it, keep it as a backup, share the song list with a duet partner, or open it in a browser on another device — all without copying a single MP3 or KAR file.

Why Export Your Catalog?

  • Disaster recovery — If your phone breaks or is lost, your song list survives as a separate file.
  • Browsing away from the app — Open the export in a browser to read, search or print your repertoire without opening the app.
  • Sharing without distributing music — Give a duet partner your song list and codes without sending them copyrighted audio files.
  • Spreadsheet planning — The reader downloads a CSV you can sort and filter for setlists.

How to Export

  1. On Android, open CONTROL and use the private Songbook export; on iPhone/iPad, choose KANTA → Songbook → Create private website copy
  2. Save the encrypted .kanta-book file
  3. Note the long code the app displays with it — both are required to open the file

The export runs entirely on your device. The website reader receives no catalog until you unlock the file locally in your own browser.

CSV Export for Spreadsheets

Once unlocked at the Songbook page, the reader can download your catalog as CSV — useful for planning a gig, tracking a repertoire, or browsing in a spreadsheet app.

Open the downloaded CSV in Google Sheets, Excel or Numbers. Filter, sort and plan setlists from it. One caution: downloaded CSV and printed pages are plaintext, so treat them like any unencrypted copy of your song list and store them accordingly.

Encryption and Privacy

The file is always encrypted, and both halves are required to read it:

  • The encrypted .kanta-book file
  • The full 32-character hexadecimal code shown on your phone

The code is not an optional password: without it the file cannot be opened, and with the wrong code decryption fails. Opening happens locally in the browser reader using the Web Crypto API — the file is never uploaded, and no catalog or search terms leave the page. The code does not expire and old exports cannot be revoked remotely, so keep the pair private. See the privacy policy for the full description.

Sharing Your Catalog (Without Sharing Your Music)

This is the most common use case:

  1. You export your Songbook as a .kanta-book file
  2. You send the file and its code to someone you trust (Signal, WhatsApp, email)
  3. They open the Songbook page and unlock it with both
  4. They see your song list and codes — but none of your audio files
  5. They find or prepare the songs themselves, using your list as a reference

This respects copyright: you're sharing information about songs, not the songs themselves. Note that the reader is a reference view — it reads the exported catalog file, not your live library, and cross-platform file exchange is still being tested.

Backup Best Practices

  • Export again after big changes — the file is a snapshot of the catalog at export time
  • Keep file and code together, but safely — both are needed; a password manager is a good home for the code
  • Treat CSV and printouts as unencrypted — they carry your full song list
  • Back up your audio separately — this export covers metadata only; your music files need their own backup
