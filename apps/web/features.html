Three original songs

Try Morning Light, Sing Together and Starlight Echo offline. KANTA includes no commercial catalog.

Playback and lyrics

Play compatible local music, follow highlighted KAR lyrics, adjust volume, tempo and pitch, and move through one ordered queue. File compatibility and physical audio behavior still need broader device testing.

Save your sets

Use Favorites and saved sessions to revisit songs. Catalog-only entries with no available media cannot be played.

Take turns

Attach singer names to reservations and manage Up Next without creating a second playback queue.

A dedicated stage

Stage views show lyrics and visuals separately from controls where the operating system provides an extended display. HDMI and AirPlay hardware acceptance is pending.

Party effects

Eight original effect buttons, separate volume and optional owner-supplied short clips. Android companion control manages songs and playback; party pads remain on the host device.

Between-song music

Choose local audio for idle time. Playback and foreground state control when it can run.

Microphone tools

Recovered iOS source includes optional input and vocal processing tools. Android can show optional dry microphone input level and pitch estimates. Separate experimental wired/USB monitoring offers Dry/Room/Hall/Echo effects; it starts muted while checking routing, and stops on a detected route change. Android 16 checks all reported outputs; older versions report only one. Physical output is unverified. Optional Android song scoring follows a single identified MIDI melody using dry input. It is off by default, shows no score for insufficient input and needs timing calibration; backing music can affect it. MP3/WAV without a melody reference remains unscored. Experimental pitch correction is a separate choice after a wired/USB monitoring route is verified. It follows nearby musical notes rather than the song melody, adds delay and can change voice tone or create artifacts. It changes monitored voice only; dry scoring stays unchanged. Each new monitor activation starts with correction off. Android front-camera preview is available separately in Scenic and turns off when backgrounded. No physical microphone quality or latency acceptance is claimed.

Testing preview

These are recovered development builds, not store releases. Android emulator checks and iPhone/iPad simulator walkthroughs passed. Physical-device audio quality, microphone latency, camera, HDMI and AirPlay acceptance remain open. YouTube streaming, ad filtering, Vocal Fit and harmonies are not included.
