Three original songs

Try Morning Light, Sing Together and Starlight Echo offline. KANTA includes no commercial catalog.

Playback and lyrics

Play compatible local music, follow highlighted KAR lyrics, adjust volume, tempo and pitch, and move through one ordered queue. File compatibility and physical audio behavior still need broader device testing.

Save your sets

Use Favorites and saved sessions to revisit songs. Catalog-only entries with no available media cannot be played.

Take turns

Attach singer names to reservations and manage Up Next without creating a second playback queue.

A dedicated stage

Stage views show lyrics and visuals separately from controls where the operating system provides an extended display. HDMI and AirPlay hardware acceptance is pending.

Party effects

Eight original effect buttons, separate volume and optional owner-supplied short clips. Android pads are Applause, Cheering, Drum Roll, Air Horn, Laughter, Ta-Da, Ding and Sad Trombone. Android companion control manages songs and playback; party pads remain on the host device.

Between-song music

Choose local audio for idle time. Playback and foreground state control when it can run.

Pitch training

Pitch is estimated on the device by a machine-learned model rather than a simple autocorrelation, and practice targets the tonic of the song's own key, read from its MIDI key signature, so a song in A minor is practised against A rather than a fixed note. The model runs locally: no microphone audio leaves the device and nothing is recorded. The meter stays neutral until the microphone reports a reading, so it never shows a score it has not earned. Pitch accuracy, latency and the confidence threshold have not yet been verified on a physical device.

Microphone tools

Recovered iOS source includes optional input and vocal processing tools. Android can show optional dry microphone input level and pitch estimates. Separate experimental monitoring offers Dry, Small Room, Room, Studio, Concert Hall, Hall, Cathedral, Plate Reverb, Slap Echo and Warm Tape. Room/Small Room and Hall/Concert Hall share tuning, so these are eight canonical modes including Dry. Wired, USB and analog line-out routes are supported in source; Bluetooth SCO/BLE headsets require Android 12 or newer. Bluetooth microphone capture is not implemented: input still comes from the phone. Speaker-class outputs remain blocked. Monitoring starts muted while checking routing and stops on a detected route change. Android 16 checks all reported outputs; older versions report only one. Physical output is unverified. Optional Android song scoring follows a single identified MIDI melody using dry input. It is off by default, shows no score for insufficient input and needs timing calibration; backing music can affect it. MP3/WAV without a melody reference remains unscored. Experimental pitch correction is a separate choice after a wired/USB monitoring route is verified. It follows nearby musical notes rather than the song melody, adds delay and can change voice tone or create artifacts. It changes monitored voice only; dry scoring stays unchanged. Each new monitor activation starts with correction off. Android front-camera preview is available separately in Scenic and turns off when backgrounded. No physical microphone quality or latency acceptance is claimed.

Android karaoke stage preview

The Android preview published from 6db012c3 includes five score bands: Excellent Singer (100), Great Singer (90–99), Good Singer (80–89), Rising Star (65–79) and Keep Practicing (50–64). Eligible results display a score floored at 50; this is not the raw measured estimate. The reveal uses a drumroll, count-up and label fade, with a reduced-motion final-score path. Physical-device timing and cue audibility remain unverified.

The scenic video library is only partially integrated. Source includes ten remote clip descriptors and download APIs, but the dialog only lists already-downloaded entries: there is no catalogue download picker. Stored SHA-256 values are computed locally, not compared with trusted expected digests. Download and stage-import behavior still need device acceptance; the bundled scenic still images remain separate.

These changes apply to Android, not the separately published iOS preview. Downloads are GitHub Actions artifacts requiring sign-in and expire; see the Android download page for current availability. Neither platform is a store release.

Testing preview

These are recovered development builds, not store releases. Android emulator checks and iPhone/iPad simulator walkthroughs passed. Physical-device audio quality, microphone latency, camera, HDMI and AirPlay acceptance remain open. YouTube streaming, ad filtering, Vocal Fit and harmonies are not included.
