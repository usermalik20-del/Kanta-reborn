Downloads and installation

Android: debug APK bundle. iPhone/iPad: unsigned IPA bundle, requiring separate personal signing. Current GitHub Actions artifact links require GitHub sign-in and expire 7 days after their build. The platform download pages show the source revision, artifact ZIP SHA-256 and exact validation runs. The Android reconstruction artifact also contains a test APK and diagnostics; the iOS artifact includes the unsigned IPA and its separate IPA checksum.

What passed

Android: 448 domain assertions, 139 API 35 emulator checks, native sanitizer tests, APK build, lint and browser Songbook interoperability. iOS: 158 Swift package tests; app compilation; three runtime walkthroughs each on iPhone and iPad simulators; unsigned device archive and IPA packaging.

What remains open

Physical audio quality and latency, microphones, cameras, HDMI/AirPlay, production signing and public app-store distribution. Android personal-media backgrounds, opt-in front-camera preview and optional microphone input level/pitch estimates are included. Experimental wired/USB monitoring and Dry/Room/Hall/Echo effects are included, with physical routing/feedback/latency still unverified. Optional song scoring estimates pitch following for a single identified MIDI melody; silence or unreliable input shows no score. Physical timing and scoring accuracy remain unverified, and backing music can affect estimates. Experimental pitch correction is included as a separate opt-in after verified wired/USB monitoring. It follows nearby notes, adds delay and may change voice tone or produce artifacts; physical sound quality remains unverified. It starts off with each monitoring activation and does not change dry scoring. Experimental Android-to-Android companion control is included. In Control, open Companion control on both devices. On the host, select its private network address and choose Start hosting. On the other Android device, enter that address and the full private 32-character code, then Connect. Share the code only with someone you trust: it grants song search, reservations, cancellation and Play/Pause/Next. The code expires in five minutes, and a session lasts up to ten minutes. Stop or leaving either app disconnects it; returning does not reconnect. Song and singer details are encrypted in transit; music and recordings are not sent. iPhone/iPad pairing is not compatible. Physical two-device testing and independent security review remain open. YouTube playback is not included.

Report a problem

Use the repository issue tracker. Include platform, app source revision from the bundle, device model, OS version, steps and the visible error. Share only information you intend to publish; do not attach personal songs, Songbook access codes or credentials.
